# Charts

This folder keeps the visual evidence used across the consulting package and final presentation.

## Round 1 evidence

The original Round 1 repository contained four PNG charts. For the final Round 2 repository, the underlying values were carried forward and the charts were recreated as lightweight SVGs using the final Taste Agent visual system so they remain readable, editable and consistent with the MVP.

- `01-letterboxd-growth.svg` — Letterboxd reported membership growth
- `02-preference-associations.svg` — strongest positive and negative Round 1 semantic preference associations
- `03-prevalence-vs-preference.svg` — prevalence vs preference association for notable Round 1 semantic signals
- `04-roi-scenarios-round1.svg` — historical Round 1 ROI scenarios using the original top-down cost estimate

The original PNG versions remain available in the Round 1 repository:

https://github.com/marctnguy/taste-agent-round1/tree/main/charts

## Round 2 update

- `05-roi-scenarios-round2.svg` — revised ROI scenarios after replacing the original top-down cost estimate with the Malt-based bottom-up implementation benchmark

The Round 1 ROI chart is retained for traceability but is **superseded for decision-making** by the Round 2 chart and `roi_risk_assessment.md`.
